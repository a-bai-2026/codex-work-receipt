# Assets

配套小程序的正式微信小程序码固定保存在：

```text
assets/miniprogram-code.png
```

它会随发布包内置，是配套小程序的公开入口素材，不包含小程序源码、AppID、密钥或后台配置。项目不提供自定义替换参数。

如果发布包中暂时没有这张图片，网页会显示明确的“待接入”占位符，不会生成伪造的小程序码。

小红书内测群二维码固定保存在：

```text
assets/xiaohongshu-beta-group-qr.png
```

它会作为本地素材嵌入生成的单文件 HTML，用于“意见反馈”弹窗，不会从远程地址加载。当前二维码有效期以图片内标注为准；失效后需要替换该文件并发布新版本。
